# Exposé 12 – Molécules actives : éclaircissants, anti-acné, solaires

Ce douzième exposé poursuit le bloc « **mode d'action** » (posture R&D) sur trois familles ciblées : **par quels mécanismes biologiques et physiques agissent les actifs éclaircissants, anti-acné et les filtres solaires ?**
L'objectif est de **mobiliser** les mécanismes, d'**analyser** des données d'efficacité ou de protection, d'**interpréter** les résultats et d'**argumenter** le choix d'un actif.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Mélanogenèse** | Production de mélanine par la tyrosinase, transfert aux kératinocytes |
| **Éclaircissants** | Inhibent la tyrosinase (kojique, arbutine) ou le transfert (niacinamide) |
| **Anti-acné** | Salicylique (BHA lipophile), niacinamide, zinc ; cible *C. acnes* et le sébum |
| **UVA / UVB** | UVB (érythème), UVA (vieillissement, pigmentation) |
| **SPF** | Mesure la protection UVB ; nécessité d'un large spectre (UVA) |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer le mécanisme d'action de chaque actif |
| **Analyser** | Lire une inhibition enzymatique, une réduction de lésions, un % de protection |
| **Interpréter** | Relier une donnée à un mécanisme |
| **Argumenter** | Choisir un actif (R&D) et évaluer une allégation |

---

## 🔬 « Test rapide » : Quel actif pour quelle problématique ?

```

1. Taches / hyperpigmentation ?

   * Inhiber la tyrosinase → acide kojique, arbutine
   * Bloquer le transfert des mélanosomes → niacinamide
   * (Hydroquinone = INTERDITE en cosmétique)

2. Acné / peau grasse ?

   * Désobstruer le follicule → acide salicylique (BHA lipophile)
   * Séboréguler / anti-inflammatoire → niacinamide, zinc

3. Protection solaire ?

   * SPF = protection UVB ; exiger un large spectre (UVA)
   * Filtres chimiques (absorbent) ou minéraux (réfléchissent)

Conclusion :

* On relie la problématique cutanée au MÉCANISME D'ACTION de l'actif

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Mélanogenèse : **tyrosinase** | Éclaircissants inhibent la tyrosinase ou le transfert des mélanosomes |
| **Hydroquinone interdite** | Réservée à l'usage médical (effets graves) |
| Salicylique = **BHA lipophile** | Pénètre le follicule sébacé (anti-acné) |
| **SPF mesure les UVB** | Exiger un large spectre (UVA) ; pas d'« écran total » |
