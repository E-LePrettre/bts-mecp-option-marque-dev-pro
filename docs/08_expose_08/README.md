# Exposé 8 – Matières premières controversées (2) : filtres UV, silicones, allergènes

Ce huitième exposé poursuit la **veille** sur trois familles souvent remises en cause : **sur quels mécanismes physico-chimiques reposent les filtres UV, les silicones et les allergènes, et qu'est-ce qui justifie leur controverse ?**
L'objectif est de **mobiliser** leurs mécanismes, d'**analyser** des données (dégradation, persistance, nombre d'allergènes), d'**interpréter** la nature du risque et d'**argumenter** en distinguant enjeu cutané et enjeu environnemental.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Filtres chimiques / minéraux** | Absorption des UV (chimiques) vs réflexion/diffusion (minéraux) |
| **Silicones** | Polymères siloxane (Si–O) : diméticone, cyclométhicone (D4, D5) |
| **Allergènes de parfumerie** | Substances à déclaration obligatoire (26 → ~80) |
| **REACH** | Règlement européen sur les substances chimiques (restrictions D4/D5) |
| **Enjeu cutané / environnemental** | Distinguer le risque pour la peau et le risque pour l'environnement |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer les mécanismes et structures de ces ingrédients |
| **Analyser** | Lire des données (dégradation, persistance, nombre d'allergènes) |
| **Interpréter** | Identifier la nature du risque (cutané / environnemental) |

---

## 🔬 « Test rapide » : Filtre, silicone, allergène — où est le problème ?

```

1. Quel est le mécanisme / la structure ?

   * Filtre chimique (absorbe les UV) / minéral (les réfléchit)
   * Silicone (polymère siloxane Si–O) / allergène de parfumerie

2. Le risque est-il CUTANÉ ou ENVIRONNEMENTAL ?

   * Allergène → risque cutané (sensibilisation)
   * Silicones D4/D5, certains filtres UV → risque environnemental

3. Que dit la réglementation ?

   * Restriction REACH (D4/D5)
   * Déclaration INCI (allergènes)
   * Interdictions locales (filtres UV et coraux)

Conclusion :

* On précise la NATURE du risque (peau vs environnement) avant de juger un ingrédient

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Filtres : **absorption vs réflexion** | Chimiques absorbent les UV ; minéraux les réfléchissent/diffusent |
| Silicones = polymères **siloxane** | Bien tolérés sur la peau ; enjeu surtout **environnemental** (D4/D5) |
| Allergènes : de **26 à ~80** | Déclaration obligatoire sur l'INCI |
| **REACH** encadre les substances chimiques | Complète le règlement cosmétique 1223/2009 |
