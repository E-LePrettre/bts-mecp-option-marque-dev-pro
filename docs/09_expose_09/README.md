# Exposé 9 – Allégations cosmétiques : cadre réglementaire et critères communs

Ce neuvième exposé porte sur ce que promet un produit : **comment la réglementation encadre-t-elle les allégations cosmétiques, et comment le niveau de preuve scientifique conditionne-t-il leur validité ?**
L'objectif est de **mobiliser** les 6 critères communs, d'**analyser** des allégations, d'**interpréter** le niveau de preuve exigé et d'**argumenter** la conformité d'une revendication.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Allégation (claim)** | Mention attribuant une caractéristique ou une fonction à un produit |
| **Règlement 655/2013** | Fixe les 6 critères communs des allégations |
| **6 critères communs** | Conformité légale, véracité, éléments probants, honnêteté, équité, choix éclairé |
| **Niveau de preuve** | Test instrumental, essai clinique, test de perception |
| **Green claims** | Allégations environnementales à étayer scientifiquement |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer les 6 critères communs |
| **Analyser** | Repérer le critère en jeu dans une allégation |
| **Interpréter** | Relier une allégation au niveau de preuve exigé |
| **Argumenter** | Conclure sur la conformité et reformuler une allégation |

---

## 🔬 « Test rapide » : Cette allégation est-elle conforme ?

```

Les 6 critères communs (655/2013) :

1. Conformité légale  → ne présente pas une obligation comme un atout ?
2. Véracité           → l'allégation est-elle vraie ?
3. Éléments probants  → est-elle prouvée, avec une preuve proportionnée ?
4. Honnêteté          → sans exagération ?
5. Équité             → ne dénigre pas la concurrence ni un ingrédient autorisé ?
6. Choix éclairé      → permet-elle au consommateur de décider en connaissance de cause ?

Niveau de preuve :

* Test instrumental / clinique → preuve d'efficacité
* Perception / auto-évaluation → ressenti, PAS efficacité mesurable

Conclusion :

* Les 6 critères respectés + preuve proportionnée → CONFORME
* Sinon → NON CONFORME

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| **6 critères communs** (655/2013) | Conformité légale, véracité, éléments probants, honnêteté, équité, choix éclairé |
| La **preuve** doit être **proportionnée** | Test instrumental/clinique > auto-évaluation |
| **Perception ≠ efficacité** | « 95 % des femmes… » = ressenti, pas une mesure |
| **Green claims** = à étayer | Preuve vérifiable, lutte contre le greenwashing |

---

## ⚠️ Lien explicite avec l'épreuve E2

> Objectif : **Évaluer la conformité d'une allégation et le niveau de preuve exigé.**

Mini-attendu typique :
- **Je repère le critère** en jeu (parmi les 6),
- **J'identifie le niveau de preuve** (instrumental, clinique, perception),
- **Je conclus** conforme / non conforme et, si besoin, **je reformule**,
- **Je conclus** clairement.
