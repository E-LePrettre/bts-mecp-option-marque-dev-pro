# Exposé 13 – Molécules actives innovantes : peptides, probiotiques, biotechnologies

Ce treizième exposé clôt le bloc « **mode d'action** » par les innovations : **sur quelles bases biologiques et physiques reposent les actifs cosmétiques innovants et leurs systèmes de vectorisation ?**
L'objectif est de **mobiliser** les mécanismes des peptides, du microbiome et des biotechnologies, d'**analyser** des données, d'**interpréter** l'apport d'une vectorisation et d'**argumenter** avec un regard critique (posture R&D).
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Peptides biomimétiques** | Courtes chaînes d'acides aminés : signal, « botox-like » partiel, transporteur |
| **Microbiome et dysbiose** | Écosystème cutané protecteur ; déséquilibre lié à l'acné, l'eczéma |
| **Pré / pro / postbiotiques** | Nourrir / apporter des micro-organismes / fractions de fermentation |
| **Biotechnologie blanche** | Production d'ingrédients par fermentation (AH, squalane) |
| **Vectorisation** | Liposome (bicouche de phospholipides), nanoémulsion, encapsulation |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer le mécanisme des peptides, du microbiome, des vecteurs |
| **Analyser** | Lire une donnée de collagène, de diversité microbienne, de protection |
| **Interpréter** | Relier une donnée à un mécanisme |
| **Argumenter** | Présenter une innovation (R&D) et garder un regard critique |

---

## 🔬 « Test rapide » : Innovation cosmétique — que regarder ?

```

1. De quelle famille s'agit-il ?

   * Peptide (signal / « botox-like » partiel / transporteur)
   * Pré / pro / postbiotique (microbiome)
   * Biotechnologie (fermentation) / vectorisation (liposome)

2. Quel est le mécanisme RÉEL ?

   * Peptide signal → relance le collagène
   * Postbiotique → aide à équilibrer le microbiome
   * Liposome → protège l'actif et améliore sa pénétration

3. L'allégation est-elle réaliste ?

   * « botox-like », « régénère », « cellules souches » → à nuancer

Conclusion :

* On garde un regard critique : mécanisme réel vs promesse marketing

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| **Peptides** = courtes chaînes d'acides aminés | Signal (collagène), « botox-like » partiel (Argireline), transporteur |
| **Microbiome** à équilibrer | Dysbiose = déséquilibre ; les **postbiotiques** dominent en cosmétique |
| **Biotech blanche** = fermentation | Acide hyaluronique par *Streptococcus*, squalane par levures |
| **Vectorisation** protège et fait pénétrer | Liposome = bicouche de phospholipides |

## ⚠️ Lien explicite avec l'épreuve E2

> Objectif : **Présenter une innovation en expliquant son mécanisme réel, sans surinterpréter les promesses.**

Mini-attendu typique :
- **Je cite le mécanisme** (signal, microbiome, vecteur),
- **Je lis la donnée** et **je la relie** au mécanisme,
- **J'évalue** l'allégation avec un regard critique,
- **Je conclus** clairement.
