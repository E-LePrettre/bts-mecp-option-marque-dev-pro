# Exposé 10 – ARPP et décryptage des allégations de fiches produits

Ce dixième exposé outille l'analyse critique de la publicité : **comment analyser de façon méthodique les allégations d'une fiche produit, et quels organismes encadrent la publicité cosmétique ?**
L'objectif est de **mobiliser** le rôle des organismes (ARPP, JDP, DGCCRF), d'**analyser** une fiche produit, d'**interpréter** le niveau de preuve d'une allégation et d'**argumenter** sa conformité.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **ARPP** | Autorité de régulation professionnelle de la publicité (autorégulation) |
| **JDP** | Jury de déontologie publicitaire (avis public sur les plaintes) |
| **DGCCRF** | Répression des fraudes ; sanctionne la publicité trompeuse (L121-1) |
| **Conditions de test** | Nombre de sujets, durée, méthode (souvent renvoyées par un astérisque) |
| **Avant/après** | Visuel qui doit rester réaliste (pas d'exagération) |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer le rôle et le pouvoir de chaque organisme |
| **Analyser** | Décrypter les allégations d'une fiche produit |
| **Interpréter** | Relier une allégation à son niveau de preuve |
| **Argumenter** | Conclure sur la conformité et proposer une correction |

---

## 🔬 « Test rapide » : Décrypter une fiche produit

```

Pour chaque allégation :

1. Est-elle prouvable ?
2. Par quel type de preuve ? (instrumentale / clinique / perception)
3. Est-elle honnête (sans exagération) ?
4. Le visuel (avant/après) est-il cohérent avec la réalité ?
5. Les mentions / conditions de test sont-elles présentes (astérisque) ?

Qui intervient en cas de problème ?

* ARPP / JDP → autorégulation (avis, pression du secteur)
* DGCCRF → sanction juridique (publicité trompeuse)

Conclusion :

* Prouvée + honnête + visuel réaliste + mentions présentes → CONFORME
* Sinon → NON CONFORME

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| **ARPP** = autorégulation | Recommandations, conseil préalable, pouvoir **incitatif** |
| Autorégulation **≠** sanction juridique | JDP (avis public) vs DGCCRF (publicité trompeuse, L121-1) |
| Allégation de résultat = **conditions de test** | Astérisque : nombre de sujets, durée, méthode |
| **Avant/après** doit rester réaliste | « photo retouchée » ne suffit pas à rendre acceptable un visuel trompeur |

---

## ⚠️ Lien explicite avec l'épreuve E2

> Objectif : **Décrypter les allégations d'une fiche produit et situer les organismes de contrôle.**

Mini-attendu typique :
- **Je décrypte** chaque allégation (prouvable ? type de preuve ? honnête ? visuel ? mentions ?),
- **J'identifie** l'organisme concerné (ARPP/JDP ou DGCCRF),
- **Je conclus** conforme / non conforme et, si besoin, **je corrige**,
- **Je conclus** clairement.
