# Exposé 14 – Tests d'efficacité instrumentaux et cliniques (scorage)

Ce quatorzième exposé ouvre le bloc « **réaliser et analyser des tests d'efficacité** » : **comment mesure-t-on objectivement l'efficacité d'un produit cosmétique, et sur quels principes physiques reposent les appareils de mesure de la peau ?**
L'objectif est de **mobiliser** les principes des mesures, d'**analyser** des résultats, d'**interpréter** la significativité statistique et de **réaliser** un mini-test argumenté.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** — avec un volet **réalisation**.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Tests instrumentaux** | Cornéométrie (capacitance), TEWL (perte d'eau), cutométrie (élasticité), colorimétrie (L*a*b*) |
| **Scorage clinique** | Cotation standardisée par un expert (échelles Bazin, ECLA) |
| **Protocole d'étude** | Témoin, placebo, essai randomisé, hémi-visage (intra-individuel) |
| **Statistiques** | Valeur p ; significativité statistique vs clinique |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer le principe physique de chaque mesure |
| **Analyser** | Lire des mesures avant/après, une comparaison traité/témoin |
| **Interpréter** | Comprendre la valeur p et la portée d'un résultat |
| **Réaliser / argumenter** | Concevoir et réaliser un mini-test, conclure |

---

## 🔬 « Test rapide » : Comment prouver l'efficacité d'un produit ?

```

1. Quel paramètre mesurer ?

   * Hydratation → cornéométrie (capacitance)
   * Barrière → TEWL (perte insensible en eau)
   * Fermeté → cutométrie (aspiration/déformation)
   * Rides → profilométrie / scorage (Bazin)
   * Teint → colorimétrie (L*a*b*, ITA)

2. Quel type de preuve ?

   * Instrumental (objectif) / clinique (scorage) / perception (subjectif)

3. Quel protocole ?

   * Témoin / placebo, hémi-visage (chacun son témoin), durée définie

4. Résultat significatif ?

   * p < 0,05 (statistique) — mais aussi significatif CLINIQUEMENT (visible) ?

Conclusion :

* Paramètre + instrument + témoin + p < 0,05 → efficacité démontrée

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Chaque appareil mesure une **grandeur physique** | Cornéométrie = capacitance, TEWL = perte d'eau, cutométrie = déformation |
| Le **scorage** est une cotation standardisée | Échelles de Bazin (rides), ECLA (acné) |
| L'**hémi-visage** : chacun son témoin | Design intra-individuel, plus puissant |
| **p < 0,05** = significatif statistiquement | ≠ significatif **cliniquement** (visible) |

## ⚠️ Lien explicite avec l'épreuve E2

Mini-attendu typique :

- **Je lis les résultats** (avant/après, traité/témoin),

- **Je conclus** clairement.
