# Exposé 7 – Matières premières controversées (1) : perturbateurs endocriniens et nanomatériaux

Ce septième exposé ouvre la **veille sur les matières premières controversées** : **que dit la science sur les perturbateurs endocriniens et les nanomatériaux, et comment la réglementation gère-t-elle l'incertitude ?**
L'objectif est de **mobiliser** les mécanismes et définitions, d'**analyser** des données d'activité ou de pénétration, d'**interpréter** ce que disent les chiffres et d'**argumenter** en distinguant science, précaution et marketing.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Perturbateur endocrinien (PE)** | Substance qui interfère avec le système hormonal (mimer, bloquer, perturber) |
| **Parabènes** | Conservateurs suspectés d'une activité œstrogénique (très faible pour les plus étudiés) |
| **Nanomatériau** | Matériau dont une dimension est < 100 nm ; propriétés modifiées |
| **Réglementation nano** | Notification + mention **[nano]** dans la liste INCI |
| **Principe de précaution** | Mesure prudente face à l'incertitude (≠ preuve de dangerosité) |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer les mécanismes d'un PE et la définition d'un nanomatériau |
| **Analyser** | Lire des données d'activité œstrogénique ou de pénétration |
| **Interpréter** | Relier les données à un mécanisme et relativiser un risque |
| **Argumenter** | Distinguer donnée scientifique, précaution et argument marketing « sans » |

---

## 🔬 « Test rapide » : Ingrédient controversé — danger ou précaution ?

```

1. Que disent les données scientifiques ?

   * Activité réelle (ex. œstrogénique) forte ou négligeable ?
   * Pénètre-t-il la peau saine ?

2. Que dit la réglementation ?

   * Autorisé, restreint (concentration) ou interdit ?
   * Nanomatériau → notification + mention [nano] sur l'INCI

3. Reste-t-il une incertitude ?

   * Oui → principe de précaution (restriction prudente)
   * Non → usage encadré

Conclusion :

* Une restriction n'est PAS une preuve de dangerosité : c'est une gestion prudente du risque
* On distingue la donnée scientifique de l'argument marketing « sans »

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Un **PE** agit sur le système hormonal | Il peut **mimer**, **bloquer** ou **perturber** une hormone |
| L'**activité réelle** peut être très faible | Parabènes : des milliers à des millions de fois moins actifs que l'œstradiol |
| Un **nanomatériau** mesure < 100 nm | Propriétés modifiées ; mention **[nano]** obligatoire |
| **Précaution ≠ dangerosité prouvée** | Restriction prudente face à l'incertitude |
