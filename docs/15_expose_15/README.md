# Exposé 15 – Tests sensoriels et questionnaire consommateur

Ce quinzième et dernier exposé complète le bloc « tests d'efficacité » par la perception : **comment évalue-t-on la perception d'un produit de façon rigoureuse, et comment construit-on un questionnaire consommateur fiable ?**
L'objectif est de **mobiliser** les méthodes d'évaluation sensorielle, d'**analyser** un profil sensoriel, d'**interpréter** un questionnaire et de **réaliser** un questionnaire consommateur.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** — avec un volet **réalisation**.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Panel expert / consommateur** | Description objective (entraîné) vs préférence (non entraîné) |
| **Descripteurs sensoriels** | Étalement, glissant, pénétration, toucher résiduel… |
| **Profil sensoriel** | Représentation en radar comparant des formules |
| **Questionnaire** | Types de questions, échelles, biais, taille d'échantillon |
| **Perception vs efficacité** | Une auto-évaluation n'est pas une preuve d'efficacité mesurable |

| Compétence | Application |
|------------|-------------|

---

## 🔬 « Test rapide » : Construire un test de perception fiable

```

1. Quel objectif ? (préférence, description, allégation à soutenir)

2. Quel panel ?
   * Expert (entraîné) → description objective
   * Consommateur (non entraîné) → préférence, ressenti

3. Des questions non biaisées ?
   * Éviter formulation orientée, effet d'ordre, complaisance, halo
   * Échelles : Likert (1–5), échelle visuelle analogique

4. Assez de sujets ? (≥ 30 pour exploiter ; 50–100 pour une allégation)

5. Que prouve le résultat ?
   * Perception ≠ efficacité mesurable

Conclusion :

* Objectif clair + panel adapté + questions neutres + échantillon suffisant → test fiable

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Panel **expert ≠** panel **consommateur** | Description objective vs préférence subjective |
| Le **profil sensoriel** se lit en radar | Compare des formules sur des descripteurs |
| Attention aux **biais** | Formulation, ordre, complaisance, halo |
| **Perception ≠ efficacité** | « 90 % des femmes… » = ressenti, pas une mesure |

## ⚠️ Lien explicite avec l'épreuve E2

> Objectif : **Réaliser et analyser un test sensoriel ou un questionnaire, et interpréter sa portée.**

Mini-attendu typique :
- **Je choisis** le panel et les descripteurs / questions adaptés,
- **J'évite** les biais et je choisis une **échelle** pertinente,
- **J'interprète** les résultats (perception vs efficacité),
- **Je conclus** clairement.
