# Exposé 5 – Allégation hypoallergénique et effets indésirables 📝

**Hypoallergénique, irritation vs allergie, allergènes, tests de tolérance**

> **Problématique.** Que garantit réellement l'allégation « hypoallergénique », et comment distinguer scientifiquement les différents effets indésirables cutanés ?

## 🧾 Vocabulaire clé

| Terme | Définition |
|-------|-----------|
| **Hypoallergénique** | Formulé pour minimiser le risque allergique (ne garantit pas l'absence de réaction) |
| **Effet indésirable** | Réaction cutanée non souhaitée liée à l'usage d'un produit |
| **Irritation (dermite d'irritation)** | Réaction **non immunologique**, toxique directe, **dose-dépendante** |
| **Allergie de contact (eczéma)** | Réaction **immunologique** retardée : **hypersensibilité de type IV** |
| **Urticaire de contact** | Réaction immédiate (papules, plaques) |
| **Photosensibilisation** | Réaction déclenchée par l'association substance + UV |
| **Haptène** | Petite molécule qui, liée à une protéine de la peau, devient allergène |
| **Cellules de Langerhans** | Cellules immunitaires de l'épiderme présentant l'allergène aux lymphocytes T |
| **Sensibilisation / déclenchement** | 1er contact (silencieux) / contacts suivants (réaction en 24–72 h) |
| **Patch-test** | Test médical qui identifie l'allergène (lectures 48 h et 96 h) |
| **ROAT** | Test d'application répétée en ouvert, pour confirmer une réactivité douteuse |
| **Allergènes déclarés** | Substances parfumantes à mentionner sur l'INCI (26 → ~80) |

## 📚 Les connaissances à mobiliser

### 1. L'allégation « hypoallergénique »

Elle signifie que le produit a été formulé pour **minimiser** le risque allergique (exclusion des allergènes connus, souvent absence de parfum). **Elle ne garantit pas** l'absence totale de réaction, et il n'existe **pas de définition réglementaire stricte** ni de test standard obligatoire. Elle doit néanmoins respecter les critères communs (véracité, éléments probants).

### 2. Les types d'effets indésirables

| Effet indésirable | Nature |
|-------------------|--------|
| Irritation | Non immunologique, dose-dépendante, dès le 1er contact |
| Allergie de contact | Immunologique retardée (type IV), après sensibilisation |
| Urticaire de contact | Réaction immédiate |
| Photosensibilisation | Substance + UV |

### 3. Irritation vs allergie : le mécanisme

| Critère | Irritation | Allergie de contact |
|---------|-----------|---------------------|
| Mécanisme | Toxicité directe (non immunologique) | Immunologique (type IV) |
| Contact préalable | Non nécessaire | Sensibilisation obligatoire |
| Personnes touchées | Tout le monde (si dose suffisante) | Seulement les sensibilisés |
| Dose | Dose-dépendante | Peu dépendante au-delà d'un seuil |
| Délai | Rapide | Retardé (24–72 h) |

L'allergie se déroule en deux temps : **sensibilisation** (l'haptène pénètre, se lie à une protéine, est présenté par les cellules de Langerhans aux lymphocytes T → mémoire immunitaire, silencieux) puis **déclenchement** (à un contact ultérieur, réaction inflammatoire en 24–72 h).

### 4. Les ingrédients les plus souvent incriminés

| Famille | Exemples |
|---------|----------|
| Parfums | 26 (puis ~80) allergènes réglementaires |
| Conservateurs | Isothiazolinones (MIT, MCIT), libérateurs de formaldéhyde |
| Colorants capillaires | PPD (paraphénylènediamine) |
| Métaux | Nickel |

### 5. Les tests de tolérance

- **Patch-test** : application des substances sous patch occlusif sur le dos, **lectures à 48 h et 96 h**. Identifie l'allergène d'un eczéma de contact. **Acte médical.**
- **Test d'usage sous contrôle dermatologique** : usage réel sous surveillance → « testé dermatologiquement », « haute tolérance ».
- **ROAT** : applications répétées en ouvert pour confirmer une réactivité douteuse.

## 🩹 ATELIER A – Lecture d'un patch-test

### Document A1 – Contexte

Un dermatologue réalise un **patch-test** : les substances sont appliquées sous patch occlusif sur le dos, avec **lecture à 48 h puis à 96 h**. Une réaction qui **s'amplifie** de 48 h à 96 h (**crescendo**) oriente vers une **allergie** ; une réaction qui **s'atténue** (**decrescendo**) oriente vers une **irritation**. (Intensité notée de 0 à +++.)

### Document A2 – Résultats

| Substance | Lecture 48 h | Lecture 96 h |
|:---------:|:---:|:---:|
| Témoin (vaseline) | 0 | 0 |
| Substance A | + | +++ |
| Substance B | ++ | + |
| Substance C | 0 | 0 |
