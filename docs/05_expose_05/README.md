# Exposé 5 – Allégation hypoallergénique et effets indésirables

Ce cinquième exposé interroge une allégation très courante : **que garantit réellement le terme « hypoallergénique », et comment distinguer scientifiquement les différents effets indésirables cutanés ?**
L'objectif est de **mobiliser** les mécanismes des effets indésirables, d'**analyser** des résultats de tests de tolérance, d'**interpréter** la différence irritation/allergie et d'**argumenter** la valeur d'une allégation.
👉 Compétences ciblées : **mobiliser**, **analyser**, **interpréter** et **argumenter** (réflexes « épreuve E2 »).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Allégation « hypoallergénique »** | Produit formulé pour minimiser le risque allergique (sans définition réglementaire stricte) |
| **Effets indésirables** | Irritation, allergie de contact, urticaire, photosensibilisation |
| **Irritation vs allergie** | Réaction non immunologique dose-dépendante vs réaction immunologique (type IV) |
| **Allergènes fréquents** | Parfums (26 → ~80), conservateurs, colorants capillaires (PPD), nickel |
| **Tests de tolérance** | Patch-test, test d'usage sous contrôle dermatologique, ROAT |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Restituer les mécanismes de l'irritation et de l'allergie |
| **Analyser** | Lire des résultats de patch-test, des fréquences de sensibilisation |
| **Interpréter** | Relier une réaction à un mécanisme (crescendo/decrescendo) |
| **Argumenter** | Évaluer ce que garantit une allégation « hypoallergénique » |

---

## 🔬 « Test rapide » : Irritation ou allergie de contact ?

```

1. La réaction touche-t-elle tout le monde (à dose suffisante) ?

   * Oui, dose-dépendante → plutôt IRRITATION (non immunologique)
   * Non, seulement certaines personnes → plutôt ALLERGIE

2. Y a-t-il eu un contact antérieur (sensibilisation) ?

   * Oui, réaction retardée (24–72 h) → ALLERGIE (hypersensibilité de type IV)
   * Non, dès le 1er contact → IRRITATION

3. Au patch-test, comment évolue la réaction de 48 h à 96 h ?

   * Elle s'amplifie (crescendo) → ALLERGIE
   * Elle s'atténue (decrescendo) → IRRITATION

Conclusion :

* Immunologique + retardée + crescendo + sujets sensibilisés → ALLERGIE
* Non immunologique + dose-dépendante + decrescendo → IRRITATION

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| « Hypoallergénique » **minimise**, ne garantit pas | Pas de définition réglementaire stricte ni de test obligatoire |
| Irritation **≠** allergie | Non immunologique / dose-dépendante vs immunologique (type IV) / sensibilisation |
| Les **allergènes** doivent être déclarés | 26 → ~80 substances parfumantes sur la liste INCI |
| Le **patch-test** identifie l'allergène | Lectures à 48 h et 96 h ; acte médical |

## ⚠️ Lien explicite avec l'épreuve E2

> Objectif : **Distinguer les mécanismes des effets indésirables et évaluer ce que garantit une allégation.**

Mini-attendu typique :
- **Je cite le mécanisme** (irritation non immunologique / allergie de type IV),
- **Je lis les résultats** (patch-test, fréquences) et **je relie** au mécanisme,
- **J'évalue l'allégation** « hypoallergénique » au regard des données et du CE 655/2013,
- **Je conclus** clairement.
